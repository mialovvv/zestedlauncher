## 💡 Почему Zested Launcher?

Большинство современных лаунчеров построены на тяжеловесных фреймворках вроде **Electron** или запускаются внутри виртуальной машины **Java**, потребляя от 300 до 800+ МБ оперативной памяти в фоновом режиме даже во время игры.

**Zested Launcher** решает эту проблему:
- 🚀 **Нативный C++17 и Win32 API**: Запуск за доли секунды, мгновенный отклик и максимальная эффективность.
- 🪶 **Всего ~15–20 МБ ОЗУ**: Практически нулевое влияние на системные ресурсы, вся оперативная память достается самой игре.
- 🌐 **Высокоскоростной WinHTTP**: Прямая потоковая загрузка манифестов, библиотек и ассетов без промежуточных рантаймов.

## ✨ Ключевые возможности

### 🔐 Авторизация аккаунтов
- **Microsoft OAuth 2.0**:
  - Быстрый и безопасный вход через встроенное окно Microsoft Edge WebView2.
  - Автоматический перехват авторизационного токена без необходимости вручную переходить на сторонние сайты.
  - Получение XBL/XSTS билетов и ключа Mojang Services.
  - Автоматическая подгрузка официального скина игрока.
- **Offline (Оффлайн) профили**:
  - Создание неограниченного количества локальных профилей с кастомными никнеймами и скинами.
  - Мгновенное переключение активного профиля в один клик.

### 📦 Каталог сборок и модов (Modrinth API)
- **Установка Modpack (`.mrpack`) в один клик**:
  - Автоматическая загрузка архива сборки, распаковка и чтение `modrinth.index.json`.
  - Перенос переопределений (`overrides`) и параллельная загрузка всех требуемых модов.
  - Информативные уведомления (toast) о ходе установки.
- **Каталог модов**:
  - Поиск оптимизационных и контентных модов (Sodium, Iris, Lithium, Fabric API и др.).
  - Установка модов напрямую в активную сборку.

### 🧩 Поддержка модлоадеров и версий
- Поддержка **Fabric**, **Forge**, **NeoForge** и чистой **Vanilla**.
- Прямая интеграция с **Mojang Version Manifest v2** — доступ ко всем официальным релизам игры.
- Изолированные игровые директории для каждой созданной сборки.

### ⚙️ Тонкая JVM-настройка
- **Автоопределение Java**: Лаунчер автоматически сканирует систему и находит установленные среды Java (Eclipse Adoptium, BellSoft Liberica, Zulu, Microsoft OpenJDK, Oracle).
- **Выделение памяти**: Удобный слайдер от 1 ГБ до 16+ ГБ оперативной памяти.
- **Оптимизированные G1GC флаги**: Встроенный пресет аргументов JVM сборщика мусора для устранения микрофризов и достижения плавного FPS.
- **Умная панель настроек**: Плавающая панель «Сохранить изменения» активируется только при реальных изменениях и автоматически скрывается при возврате значений или переходе между вкладками.

## 🎨 Дизайн и интерфейс

Интерфейс Zested Launcher вдохновлен концепцией **Aurion Glassmorphism**:
- 🌌 **Глубокая темная эстетика**: Полупрозрачные акриловые карточки, размытие фона (`backdrop-filter`) и неоновые акценты.
- 🪟 **Нативное скругление окна**: Физическое скругление углов окна Win32 (`CreateRoundRectRgn`) в сочетании с алгоритмами DWM Windows 11.
- 🌊 **Плавная анимация**: Отсутствие дёрганий навигации, плавный скроллинг списков (`smooth scrolling`), интерактивные состояния кнопок и всплывающие тосты.

## 🛠️ Сборка из исходников

Для компиляции лаунчера вам понадобится компилятор с поддержкой **C++17** (рекомендуется **MinGW-w64 / GCC** или **w64devkit**).

### 1. Клонирование репозитория
```powershell
git clone https://github.com/mialovvv/zestedlauncher.git
cd zestedlauncher
```

### 2. Сборка через PowerShell
В корне репозитория расположен готовый скрипт сборки [build.ps1](file:///C:/Users/User/Documents/projects/mod/arefulauncher/build.ps1):
```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт автоматически скомпилирует `src/main.cpp`, слинкует необходимые системные библиотеки (`WebView2Loader`, `winhttp`, `dwmapi`, `gdi32`) и создаст исполняемый файл **`zestedlauncher.exe`**.

### 3. Запуск
```powershell
.\zestedlauncher.exe
```

## 📁 Архитектура проекта

```text
├── sdk/                      # WebView2 SDK (C++ заголовки и библиотеки импорта)
├── src/
│   ├── main.cpp              # Точка входа, Win32 окно, диспетчер WebView2 сообщений
│   ├── http_client.hpp       # Нативный WinHTTP клиент (GET, POST, стриминг в файл)
│   ├── auth_manager.hpp      # Менеджер Microsoft OAuth2 и оффлайн профилей
│   ├── instance_manager.hpp  # Управление изолированными сборками и модами
│   ├── game_launcher.hpp     # Сборка classpath, загрузка ассетов/библиотек и старт JVM
│   ├── modrinth_api.hpp      # Интеграция с каталогом модов и модпаков Modrinth
│   ├── mojang_api.hpp        # Mojang Version Manifest v2 и Fabric Meta API
│   └── ui_resources.hpp      # Встроенная верстка интерфейса (HTML/CSS/JS)
├── build.ps1                 # Автоматизированный скрипт компиляции
└── README.md                 # Документация проекта
```
